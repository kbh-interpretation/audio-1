# Копенгагенская интерпретация: audio, part 1

The audio files of the podcast «Копенгагенская интерпретация», served by GitHub Pages at
`https://kbh-interpretation.github.io/audio-1/`. The feed is <https://kbh-interpretation.github.io/feed.xml>
(repository `kbh-interpretation/kbh-interpretation.github.io`).

Podcast apps link to these files: never rename or replace a published file. GitHub Pages caps a site at 1 GB and a
file at 100 MiB, so later episodes go to `audio-2` once this one nears 900 MB.

Episodes #1–#9.2 came from Spotify for Creators on 2026-10-31 and 2026-11-01:
- six files are the ones Spotify served, unchanged;
- #4 and #7 were over the 100 MiB limit, so they were re-encoded with Apple's AAC encoder, with the same duration and
  loudness:
  - #4: MP3 320 kb/s, 180 MB → AAC 128 kb/s;
  - #7: AAC 128 kb/s, 111 MB → AAC 112 kb/s;
- #3 and #8 are encoded with the same encoder at 128 kb/s from the show's own mixes of their first release, which are
  longer than the later versions Spotify served:
  - #3: 1:03:27 instead of 1:00:54;
  - #8: 1:16:00 instead of 1:07:31.
